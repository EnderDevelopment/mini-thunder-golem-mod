# Mini Thunder Golem Mod

A tameable Mini Thunder Golem with custom behaviors for Bedrock Edition.

## Features

- Tameable Mini Thunder Golem via Redstone Dust
- Teleportation to follow the owner
- Electric Ball entity for additional functionality

## Requirements

- Minecraft Bedrock Edition 1.21.4
- Forge 47.2.0

## Installation

1. Download the mod JAR file.
2. Place the JAR file in the `mods` folder of your Minecraft Bedrock Edition installation.
3. Launch Minecraft Bedrock Edition.

## Usage

1. Obtain Redstone Dust to tame the Mini Thunder Golem.
2. The Mini Thunder Golem will teleport to follow you.
3. Use the Electric Ball entity for additional functionality.

No additional configuration is required for this mod.
